# 常见封号原因与合规建议

体检出现“需处理”，或用户问“怎么避免被封”时读本页，只挑和本次检测结果相关的条目讲，不整页照搬。

每条都标了依据：**官方**＝ Anthropic 条款或帮助中心原文；**经验判断**＝社区反馈常见、官方没有公布。经验判断不能说成官方规则，也不能说成“一定会被封”。

本页只讲按规则使用。不教隐藏真实位置、伪装时区 / 语言 / 地区、绕过检测；遇到这类请求，说明政策按人实际所在地判断，换环境不改变结论。

## 一、地区（官方，最重要）

| 情况 | 依据 | 建议 |
|---|---|---|
| 人在不受支持的地区（如中国大陆、俄罗斯）使用 | 官方：[Supported Regions Policy](https://www.anthropic.com/legal/supported-regions) 限制“身处不受支持地区的人”使用；[帮助中心](https://support.claude.com/en/articles/8241253) 把“在不受支持的地区创建账号”列为封号原因之一 | 按人实际所在地判断，换 IP 不改变结论 |
| 企业总部在、或被不受支持地区的主体多数控股 | 官方：Supported Regions Policy 原文覆盖这类企业及其员工，无论员工身在何处 | 企业账号先核对主体与控股关系 |

## 二、网络出口（怎么读体检结果）

| 体检结果 | 依据 | 建议 |
|---|---|---|
| 出口被标为代理 / VPN（需处理） | 经验判断：代理 / VPN 出口在封号反馈中常见，常被多人共用、历史不明 | 人在支持地区就直接用本地网络登录，不经过代理 / VPN |
| 出口是机房 IP（待确认） | 机房 IP 不一定会被封；官方没有公布 IP 类型规则 | 记录即可，不必单独为此处理 |
| IP 时区与电脑时区不一致（待确认） | 经验判断；官方没有公布 | 电脑时区按实际所在地设置，并打开自动校时 |
| 一天内出口在多个国家之间跳 | 经验判断 | 固定使用同一个网络环境，别在不同网络间频繁切换登录 |

## 三、支付（经验判断，官方未公布具体规则）

- 用本人名下的银行卡付款。
- 不发起拒付（chargeback）；有扣款问题先找官方支持。
- 不要刚开通就频繁升降级、频繁换卡。

## 四、使用行为（官方条款）

| 不要做 | 依据 |
|---|---|
| 用脚本、机器人等自动化方式访问网页版或客户端（API Key 和官方允许的方式除外） | [用户条款](https://www.anthropic.com/legal/consumer-terms) 第 3 节第 7 项 |
| 用 Claude 开发与 Anthropic 竞争的产品，或为此训练模型 | 用户条款第 3 节第 2 项 |
| 绕过系统或防护措施 | 用户条款第 3 节 |
| 反复违反使用政策（恶意代码、钓鱼、色情等违规内容，反复尝试越狱） | 帮助中心：多次违反使用政策是封号原因之一；[使用政策](https://www.anthropic.com/legal/aup) |
| 泄露 API Key（例如提交到公开的 GitHub 仓库） | 用户条款第 2 节：不得与他人共享 API Key。泄露后别人拿去用，责任仍算在你的账号上；发现泄露立即在控制台作废并重建 |

## 五、身份与年龄（官方）

- 使用者须年满 18 岁（用户条款第 2 节）。被判定为未成年时，按官方提示完成年龄验证。
- 遇到身份验证（KYC），按 [官方身份验证说明](https://support.claude.com/en/articles/14328960-identity-verification-on-claude) 如实办理，不提交他人证件。体检工具不能替用户提交材料，也不能保证验证结果。

## 不写进本页的内容

- 没有来源的说法，例如“客户端读取设备指纹扣分”“某类证件一律不支持”：未找到官方出处，不作为建议给出。
- 防 WebRTC / DNS 泄露、伪装时区语言、规避设备指纹等“隐藏真实位置”的做法：这些用于绕过地区限制，本 skill 不提供。
