查看当前账号的 KYC 状态

先打开已登录的 Claude 页面。检查只在你点击后执行，结果不保存、不上传。

如何理解状态

无需验证、审核中、已通过、审核被拒，是接口返回的 KYC 状态。HTTP 403 表示查询请求被拒，不能据此认定 KYC 审核被拒。未知状态保留原值，需进一步核对。

看看此浏览器的网络请求

开始后会访问 ipify 回显服务，对方会看到出口 IP。此结果不代表 Claude Code 或其他程序的出口。

尚未检查

语言、时区与网络出口不一致很常见，不是账号被封或将被封的证据。

WebRTC 候选

此检测会向 Google 的 STUN 服务器（stun.l.google.com:19302）发送请求，对方会看到你的网络地址。不点确认就不发送。

未检测

候选地址只反映本次 WebRTC 收集结果，无法据此判断其他应用的连接路径。

当前无需验证不等于已通过 KYC，多组织结果不能代表整个账号安全。
