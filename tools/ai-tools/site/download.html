启动方式

Windows 下载后运行 .exe。macOS 下载对应架构的 ZIP，解压后双击 AI Tools.command。终端会显示本机地址，并自动打开浏览器；标签页关掉后，可从终端复制地址重开。点击页面右上角“退出程序”或在终端按 Ctrl+C 结束。macOS 包尚未签名公证；如果系统提示身份不明，确认来源与校验值后，可由你本人在“系统设置 → 隐私与安全性 → 仍要打开”中决定是否允许此程序。不要关闭全局安全保护。

只想采集终端配置，可运行 aitools net --offline --json。程序位于当前目录时命令前加 ./，Windows 使用实际 .exe 文件名。

安装扩展

解压扩展 ZIP，在 Chrome 的扩展管理页开启开发者模式，再选择“加载已解压的扩展程序”，指向解压后的 extension 目录。尚未上架 Chrome 商店。
