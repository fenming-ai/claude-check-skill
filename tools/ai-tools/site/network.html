02 / 浏览器与本机

同一台电脑，
也可能走不同的网络。

浏览器能打开，不代表 Claude Code 的代理配置相同。分别检查两条路径，保留每次请求的证据。

下载检测工具

只看浏览器：使用扩展

查看访问 ipify 时观测到的 IPv4、IPv6，以及浏览器语言、时区。WebRTC 单独开启，每次确认后才联系 Google STUN 服务。

排查 Claude Code：运行本地程序

  1. 按系统下载本地程序，启动后在浏览器操作。程序只监听本机。
  2. 填入项目目录，先检查配置来源。需要测试连通性时勾选网络请求。
  3. 展开测试结果，查看 DNS、连接、TLS 和 HTTP 阶段。可以导出脱敏报告。
报告固定分区
检测器环境      本程序读取到的环境变量
配置证据        用户、项目、本机项目与固定策略文件
测试请求结果    直连 / 代理，各阶段响应
运行中的 Claude 未检测

本版支持不带认证的 HTTP/HTTPS 代理测试。SOCKS、带密码的代理和自定义 CA 会明确标注限制，不会偷偷改用直连。

此结果只说明连接情况，不判断账号状态。网络服务会看到测试请求的出口 IP；配置和聊天不上传。
