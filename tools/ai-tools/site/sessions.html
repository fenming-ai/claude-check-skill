03 / 本地记录

找回对话里的那句话。

按项目、日期与关键词检索已有 JSONL 记录，先预览，再导出 Markdown。工具不会修改源文件。

下载本地程序

从一段关键词开始

  1. 切换到“会话记录”，使用默认 Claude 记录目录，或添加你明确选择的备份目录。
  2. 点击扫描，再按项目、UTC 日期或关键词缩小范围。多个关键词按全部包含匹配。
  3. 点开记录查看文字。子任务默认折叠，工具调用、图片与思考块不会展示正文。
  4. 导出 Markdown 后自行保存。导出文件包含对话原文，分享前请检查内容。
示例关键词
代理 配置
数据库 迁移
上周讨论的项目名称

单次最多扫描 5000 个文件、128 MiB、60 秒；超出范围会提示部分完成。坏行不会阻止其他记录显示，无法识别的格式会注明。

只能找到磁盘中仍存在的记录。已删除、没有备份的数据不能靠本工具恢复。
